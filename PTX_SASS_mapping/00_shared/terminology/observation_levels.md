# 统一观测层次

| 层次 | 保留内容 | 适合回答的问题 |
|---|---|---|
| `exact` | 原始机器码、控制字段、relocation、物理寄存器和完整指令顺序 | 某个 PTX 字段是否改变真实编码，调度控制是否同时变化 |
| `allocation` | 规范化寄存器编号，但保留 GPR/UR、P/UP、寄存器宽度、寄存器对、操作数槽位、别名关系和谓词极性 | 差异是否只是寄存器分配，操作数类别和数据流是否稳定 |
| `semantic` | 目标 effect slice 的 def-use、CFG、内存效应、同步效应和完成关系 | 两段不同 SASS 是否实现同一 PTX 语义 |

任何报告都应明确使用哪一层比较。删除、融合、展开、复制和无法归属必须作为 lowering 类别记录，不能通过删除差异强行归一化成相同 opcode 序列。
