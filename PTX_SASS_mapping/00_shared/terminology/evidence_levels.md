# 证据等级

| 等级 | 最低要求 |
|---|---|
| `DETERMINISTIC` | 冻结适用域内有单因素或结构性证据，全部支持样本一致，反例数为零，并记录可证伪边界 |
| `CONDITIONAL` | 规则只在明确的变体、操作数来源、优化级、架构或上下文中成立 |
| `OBSERVATION` | 数据中稳定出现，但没有隔离因果字段，或可能混入寄存器分配和调度控制 |
| `UNVERIFIED` | 来自规范推断、外部材料或待测假设，尚未由本实验独立验证 |

证据记录至少包含环境指纹、支持计数、反例计数、代表 case、原始产物链接和限制。静态反汇编只支持编译 lowering 结论；描述符位域、内存可见性和数值正确性需要独立运行时证据。
