# Special register 族实验设计

> 适用范围：PTX ISA 9.0、NVIDIA Thor、`sm_110a`、CUDA 13.0（ptxas V13.0.88、nvdisasm V13.0.85）
> 本文性质：实验设计裁决 + 首轮校准记录。文中"实测"来自本机全量校准探针（47 个 special register 各一条读探针的 O0/O3 反汇编 + `%tid`/`%ctaid` 两组 manipulation check + `.reqntid` 对照 + 负向枚举）与已建成旗舰套件 `thread-index/thor_ptx90/`（24 syntax + 46 expanded case，O0–O3 共 280 次编译/归属，9 个带诊断锚定的负向探针）的全量自检。探针在会话 scratchpad（`calibration_results.json`/`manipulation_results.json` 等）；套件可完整重现 thread-index 组的结论。
> 设计基线：`01_tcgen05` 的静态实验分层与 `02_tma/实验设计.md` 的文档结构，逐条吸收 `01_tcgen05/对抗式审查_实验设计缺口.md` 的 P0/P1 结论；族 README 的 manipulation check 门槛（"落到 S2R/GPR/UR 是观测结果不是假设"）作为本族核心方法论执行。

## 结论

"special register 读取"在 SASS 层**不是一类东西**。47 个寄存器按 producer 机制分五类，且同一寄存器的 producer 会随消费者 uniformity 改变（见 manipulation check）——因此本族的映射规则必须写成"寄存器 × 消费者形态 → producer"二维表，一维的"寄存器 → 指令"表是错的。

| 类别 | 寄存器 | producer 机制 |
|---|---|---|
| S2R 直译 | `%tid.{x,y,z}`、`%ctaid.{x,y,z}`、`%laneid`、`%lanemask_{eq,le,lt,ge,gt}`、`%smid`、`%cluster_ctarank` | 1 条 `S2R Rd, SR_*`（`SR_TID.*`/`SR_CTAID.*`/`SR_LANEID`/`SR_{EQ,LE,LT,GE,GT}MASK`/`SR_VIRTUALSMID`/`SR_CgaCtaId`）；`%ctaid` 在 uniform 消费下改路由为 `S2UR UR, SR_CTAID.*` |
| CS2R 时钟直译 | `%clock`、`%clock_hi`、`%clock64`、`%globaltimer`（及 `_lo/_hi`） | `CS2R[.32] Rd, SR_CLOCKLO/SR_CLOCKHI/SR_GLOBALTIMERLO/HI`（64 位形态一条 `CS2R` 取寄存器对） |
| 常量 bank 折叠 | `%ntid.{x,y,z}`→`c[0x0][0x360/0x364/0x368]`、`%nctaid.{x,y,z}`→`c[0x0][0x370/0x374/0x378]`、`%gridid`→`LDC.64 c[0x0][0x140]`、`%nsmid`→`c[0x0][0x2d0]`、`%current_graph_exec`→`LDC.64 c[0x0][0x2e8]` | 无 S2R；1 条 `LDC`（ABI 保留偏移，位于用户参数区之外）。`%current_graph_exec` 在 sm_110a **合法**且是普通常量槽（族 README 的疑问已定论） |
| 位段提取序列 | `%warpid`（`S2R SR_VIRTID`+`SHF.R`+`SGXT.U32 0x7`）、`%nwarpid`（`S2R SR_VIRTCFG`+`SHF.R`+`SGXT.U32 0x8`） | 硬件寄存器打包多个字段，PTX 寄存器对应其中一个位段 |
| 合成/组合序列 | `%clusterid.*`、`%cluster_ctaid.*`、`%cluster_nctaid.*`、`%cluster_nctarank`（由 `S2UR SR_CTAID.*`+`CS2R SR_CgaSize`+整数/浮点算术合成）；`%total_smem_size`（`LDC c[0x0][0x16c]`+`S2UR SR_SMEMSZ`+`IADD3`）；`%aggr_smem_size`（`S2R SR_SMEMSZ`+CgaSize 修正）；`%dynamic_smem_size`（**带寄存器索引的常量装载** `LDC c[0x0][Rn+0x2ac]`） | 无单一硬件寄存器；ptxas 用多条指令合成，序列结构是本组的观测对象 |

## Manipulation check（族门槛的执行结果）

同一寄存器、不同消费者形态的实测（O3）：

| 消费者 | `%tid.x` | `%ctaid.x` |
|---|---|---|
| 直接落地 | `S2R SR_TID.X` | `S2R SR_CTAID.X` |
| 地址派生 | `S2R`+`IMAD.WIDE.U32` | 同左 |
| 谓词 | `S2R`+`ISETP`+`@P0 EXIT` | 同左 |
| 与 uniform 值混合运算 | `S2R`（自身不变）——但同 kernel 的 `%ctaid` 变 `S2UR` | **`S2UR UR, SR_CTAID.X`**（改路由进 UR 文件） |
| `shfl.sync.idx` 广播 | `S2R` 且 `SHFL.IDX` **保留** | `S2R` 且 `SHFL.IDX` **被消除**（可证明 warp-uniform，广播是空操作） |
| 双读 | CSE 成单条 `S2R` | 同左 |
| divergent 分支内 | `S2R` 不变，分支转谓词化 | 同左 |

结论：**producer 选择（S2R vs S2UR vs 常量 bank）与消费指令的存留（SHFL 是否消除）都是 ptxas uniformity 分析的输出**，读指令本身的语法不决定它们。套件因此把 consumer 作为一等因子（4 档全因子），并用 `shfl_broadcast`/`divergent_branch` 两个 CTX 对照 `%tid` 与 `%ntid` 的相反命运（`%ntid` 的 SHFL 被消除、`%tid` 的保留）。

## 合法面实测（旗舰套件负向探针 + 校准反转）

| 探针 | 结果/诊断 |
|---|---|
| `mov.u32 %r, %tid;`（缺分量选择子）及 `%ntid` 补集 | "Argument vector size mismatch" |
| `mov.v2.u32 {..}, %tid;`（v2 绑 v4 寄存器） | "Argument vector size mismatch" |
| `mov.u32 %r, %tid.q;` 及 `%ntid.q` 补集 | "Unknown vector selector" |
| `mov.u64/s64 %r, %tid.x;`（宽度错配，含符号性补集） | "Arguments mismatch for instruction 'mov'" |
| `mov.u32 %r, %tid_bogus;` | "Unknown symbol" |
| **校准反转**：`%tid.w` 预期非法，实测**合法**且折叠为 `MOV Rd, RZ`（不发 S2R）；`.r/.g/.b/.a` 是 `.x/.y/.z/.w` 的合法 RGBA 别名（SASS 相同） | P0-2 要求的"预期非法却合法"发现，已并入 expanded（`spelling_rgba`、`vector_read_v4` 的 w 分量） |

## 审查缺口对应设计

| tcgen05 缺口 | 本族对应设计 |
|---|---|
| P0-1 控制位是全局资源 | 本族对应物是 **GPR/UR producer 路由**：同一条 `mov.u32 %r,%ctaid.x` 因消费者 uniformity 产生 `S2R` 或 `S2UR` 两种 lowering——"编码由区域决定"的 sreg 形态；manipulation check 表已固化，套件 `shfl_broadcast`/`divergent_branch` CTX 可重现 |
| P0-2 合法面未证伪 | 9 条负向探针全带 `expected_diagnostic`（选择子/矢量宽度/位宽/未知符号四类约束各有独立诊断，拒绝可归因）；`%tid.w` 合法性反转与 RGBA 别名是补集抽样的直接产出 |
| P0-3 组合不足 | syntax 是 kind × dim × consumer 全因子（2×3×4=24），不是单因素扫描；expanded 追加 8 个 CTX（含 `double_read` CSE、`vector_read_v4` 死分量消除） |
| P1-1 模板未受控 | `template_wide`（pad 参数乱序）证实 sreg 常量槽在用户参数区外不受扰动；**`.reqntid 8,4,2` 对照证实启动界限提示不把 `%ntid` 折成立即数**（tcgen05 审查点名的"隐藏全局变量"在本族的直接检验，结论：`LDC` 保留） |
| P1-2 重物化前提 | sreg 自身就是 producer 端点，无操作数可间接化；对应设计换成 consumer 端的地址派生/多次使用（值进入后续不可折叠计算） |
| P2 边界 | 套件接受 `--ptxas/--nvdisasm` 路径参数；常量 bank 偏移表（0x360 等）是 ABI 事实，跨 CUDA 版本重跑时应优先复核该表 |

## 各组研究重点

- `thread-index`（`FRAMEWORK_VALIDATED`）：套件见 [thread-index/thor_ptx90/](thread-index/thor_ptx90/)；后续轴是 `%tid` 参与地址合并（`IMAD.WIDE` 融合）的形态学。
- `cta-grid-index`（`DESIGNED`）：`%ctaid` 的 S2R/S2UR 路由是本族 P0-1 主战场，套件应把"uniform 消费比例"做成多档 CTX；`%gridid` 是 64 位常量槽。
- `warp-lane-index`（`DESIGNED`）：`%warpid`/`%nwarpid` 是 `SR_VIRTID`/`SR_VIRTCFG` 位段提取序列，需记录 `SGXT` 位宽常量（0x7/0x8）作为编码事实；`%laneid`/`%lanemask_*` 是纯 S2R。
- `sm-and-cluster-index`（`DESIGNED`）：cluster 族全部是合成序列（`SR_CTAID`+`SR_CgaSize` 算术，含 `I2FP/FMUL` 浮点除法习语），序列模板按 tcgen05 B 类方法建表；`%smid`→`SR_VIRTUALSMID` 直译。
- `clock-and-timer`（`DESIGNED`）：`CS2R` 家族；重点是 64 位读的原子性表述（单条 `CS2R` 取对）与双读是否 CSE（时钟语义上不应 CSE，需专项验证——这是"编译器可能做错"的候选点）。
- `shared-memory-size`（`DESIGNED`）：三个寄存器三种机制（组合序列/索引常量装载/带修正的 S2R），是本族机制最杂的组，套件前先补 `.reqnctapercluster` 等启动属性对照。
- `performance-and-runtime`（`DESIGNED`）：`%current_graph_exec` 已定论（常量槽 0x2e8）；其余性能计数器待枚举合法性。
- `lane-mask`（`DESIGNED`）：五个 `SR_*MASK` 纯直译，套件价值低，可与 warp-lane-index 合并建设。

## STATIC_ONLY 边界声明

本文与套件的全部结论限于静态编译与反汇编：producer 机制、路由条件、常量槽位、序列结构。时钟单调性、`%dynamic_smem_size` 的运行时取值、cluster 合成序列的数值正确性等都需要运行时 oracle，不在本轮 PASS 含义内。
