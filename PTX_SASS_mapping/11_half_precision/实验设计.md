# F16 与 F16x2 族实验设计

> 适用范围：PTX ISA 9.0、NVIDIA Thor、`sm_110a`、CUDA 13.0（ptxas V13.0.88、nvdisasm V13.0.85）
> 本文性质：实验设计裁决 + 首轮校准记录。文中"实测"来自本机 f16 校准探针（10 个 opcode 的标量/packed 代表形态 O0/O3、neg/abs 折叠对照、立即数与打包 producer 探针）与已建成旗舰套件 `fma/thor_ptx90/`（8 syntax + 21 expanded case，O0–O3 共 116 次编译/归属，10 个带诊断锚定的负向探针）的全量自检。探针在会话 scratchpad；套件 `suite_spec.py` 文档字符串同步记载校准结论。
> 设计基线：`01_tcgen05` 的静态实验分层与 `02_tma/实验设计.md` 的文档结构，逐条吸收 `01_tcgen05/对抗式审查_实验设计缺口.md` 的 P0/P1 结论。族 README 的"packed 两个 lane 独立变化"门槛已落实为 `lane_asym_pack` 一等 CTX。

## 结论

本族在 `sm_110a` 上**没有标量 f16 SASS 指令**：标量与 packed 形态共用同一套 `H*2` 双元指令，区别只在操作数 selector——这是本族最重要的结构事实，决定了标量/packed 不是两个映射，而是同一映射的两种 selector 配置：

| PTX 形态 | SASS |
|---|---|
| `fma.rn.f16`（标量） | `HFMA2`，三个源操作数**全部带 `.H0_H0` selector**（取低半复制） |
| `fma.rn.f16x2`（packed） | `HFMA2`，操作数**无 selector**（双 lane 原样） |
| `.ftz` / `.sat` | `HFMA2.FTZ` / `HFMA2.SAT`（可叠加，独立进助记符） |
| `.rn` | **不进 SASS 助记符**（唯一合法舍入档，无信息量） |

关键 lowering 规则（全部实测）：

1. **舍入面**：`.rn` 强制且唯一。省略 → "Rounding modifier required"；`.rz/.rm/.rp` → "Illegal rounding modifier"。与 `06_cuda_core_fp` 的 f32 fma（四档全合法且进助记符）结构性不同，两族不共享结论。
2. **neg/abs 折叠**：`neg.f16`/`abs.f16` producer 喂给 fma 操作数时，O3 折叠进**同一条 `HFMA2` 的操作数符号/绝对值位**（无独立 `HADD2`）；O0 则保留独立的 producer 指令。这是"同一 PTX 序列，O 档改变指令边界"的直接证据，归属逻辑必须允许目标指令吸收前驱。
3. **立即数面**：f16 算术**从不接受立即数源**（"Arguments mismatch"）；常量必须先 `mov.b16 %r, 0x3C00;` 物化。与整数/f32 族的立即数槽位形成对照。
4. **打包 producer**：`mov.b32 %packed, {%lo, %hi};` lower 为 `PRMT`；lane 非对称输入（两 lane 独立来源）经此路径构造，是 packed 语义测试的强制前提（族 README 门槛）。
5. **修饰符顺序**：PTX 文本中 `.ftz.rn` 与 `.rn.ftz` 解析等价（`spelling_modifier_order` CTX 固化）。

## 合法面实测（负向探针，全部带诊断锚定）

| 探针 | 诊断 |
|---|---|
| 省略舍入（标量与 packed 各一条） | "Rounding modifier required" |
| `.rz` / `.rm` / `.rp` | "Illegal rounding modifier" |
| `fma.rn.b16`（无类型 b16 形态） | "Unexpected instruction types" |
| `fma.rn.neg.f16`（臆造 .neg 修饰符） | "Unknown modifier" |
| 立即数源操作数 | "Arguments mismatch" |
| 补集：单操作数宽度错配（b 槽 .b32） | "Arguments mismatch" |
| 补集：目的宽度错配（.b32 目的接标量 f16） | "Arguments mismatch" |

## 审查缺口对应设计

| tcgen05 缺口 | 本族对应设计 |
|---|---|
| P0-1 控制位是全局资源 | expanded 含 `fma_chain`（串联依赖）与 `fma_parallel_x3`（三条独立并行）两档在飞结构；runtime 保留全函数编码供控制字差分 |
| P0-2 合法面未证伪 | 10 条负向探针全带 `expected_diagnostic`，舍入/类型/修饰符/操作数四类约束诊断可归因；2 条补集抽样（操作数与目的宽度错配）在核心假设之外采样 |
| P0-3 组合不足 | syntax 是 dtype × ftz × sat 全因子（8）；`.ftz.sat` 双修饰符组合显式在矩阵内；neg/abs 折叠是跨指令组合轴 |
| P1-1 模板未受控 | expanded 含 `template_wide` |
| P1-2 重物化前提 | 操作数来自 `ld.global`（不可折叠）；`lane_asym_pack` 的两个 lane 独立装载；`neg_producer`/`abs_producer` 是带语义的间接 producer |
| P2 边界 | 套件接受 `--ptxas/--nvdisasm` 路径参数；`.H0_H0` selector 约定是最可能随架构漂移的编码细节，跨版本优先复核 |

## 各指令研究重点

- `fma`（`FRAMEWORK_VALIDATED`）：套件见 [fma/thor_ptx90/](fma/thor_ptx90/)；后续轴是 f32 累加形态（`fma.rn.f32.f16` 混合精度若合法）与 `.relu` 类附加修饰符的支持面。
- `add`/`sub`/`mul`（`DESIGNED`）：预计 `HADD2`/`HMUL2` 同构（标量 `.H0_H0` selector 规则应当复用，但按族口径必须独立实测）；sub 是否为 HADD2 + 符号位待定论。
- `min`/`max`（`DESIGNED`）：预计 `HMNMX2`，NaN 语义修饰符（`.NaN` 传播档）是重点。
- `abs`/`neg`（`DESIGNED`，折叠类）：孤立形态与被消费形态的二元对照是套件主轴（本文已证实 fma 消费路径的折叠）；孤立形态的 SASS（`HADD2` 加符号位？`LOP3` 位操作？）待定论。
- `set`/`setp`（`DESIGNED`）：预计 `HSETP2`，谓词对（packed 双 lane 出双谓词）的结构是与标量族最大的分叉点。

## STATIC_ONLY 边界声明

本文与套件的全部结论限于静态编译与反汇编。packed 双 lane 的数值独立性、`.sat`/`.ftz` 的实际数值行为、NaN bit pattern 传播都需要逐 lane 运行时 oracle（族 README 门槛），不在本轮 PASS 含义内。
